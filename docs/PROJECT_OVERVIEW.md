# Study Buddy -- Project Overview

## 1. Introduction

Study Buddy is a unified academic learning and practice platform
intended to bring common student learning activities into one place. It
combines course access, learning materials, assessments, coding
practice, study planning, AI assistance, and faculty-oriented academic
management.

## 2. Problem Being Addressed

Students often switch between separate applications to access notes,
practise programming, ask questions, and organise their study schedules.
This fragmented workflow can make learning less organised. Study Buddy
aims to provide a more centralised experience.

## 3. Main User Roles

-   **Student:** explores courses, enrols, studies lessons, attempts
    quizzes, submits assignments, practises coding, and tracks progress.
-   **Faculty:** manages learning content, reviews enrolments, creates
    assessments, and evaluates submissions.
-   **Administrator:** supports platform-level administration and user
    management.

## 4. Major Functional Areas

-   Course catalogue and enrolment workflow
-   Modules, lessons, lesson checks, and quizzes
-   PDF assignment submission and faculty evaluation
-   Browser-based CodeLab
-   AI Tutor and learning-material summarisation
-   Study Planner and personal notes
-   Achievements and course certificates
-   Faculty dashboard and student progress monitoring
-   Machine-learning-based course recommendations and performance
    insights

## 5. Technology Summary

The project description identifies React and Vite for the frontend,
Node.js and Express for the backend, MongoDB Atlas for data storage, JWT
and bcrypt for authentication, Monaco Editor for code editing, Pyodide
and Judge0 for code execution, Google Gemini API for AI features, and
Python with Scikit-learn for machine-learning components.

## 6. Intended Outcome

The intended outcome is a single academic workspace that supports both
independent student learning and faculty-managed academic activities.
