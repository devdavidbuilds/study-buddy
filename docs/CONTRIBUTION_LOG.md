## Suggested Documentation Tasks

-   Keep the project overview aligned with the current implementation.
-   Update the user guide when student or faculty workflows change.
-   Run the manual testing checklist after major feature updates.
-   Add screenshots only when they reflect the current application.
-   Record known limitations and setup notes after confirming them with
    the development team.

## Important

Only record work that has actually been completed. Update the date,
contributor name, and review status when submitting a real documentation
contribution.
